# プロジェクトとプロジェクトマネージメント

## プロジェクトは
- 1つまたは複数の定義された目標を達成するための有期的な取り組み
- 独自のプロダクト、サービス、所産を創造するために実施される有期的な業務

```
プロジェクトーー独自性              定常業務ーー反復性（PDCA)
          ｜ー有機性                     |ー継続性
```
### プロジェクトの成功のために必要なもの
QCDのバランス
Q=価値実現に必要な**品質**
C=生み出す価値に見合った**コスト**、採算性
D=タイムリーに価値提供するための**納期**

→　いずれかを優先させると他の要素が疎かになる関係
→　独自性に伴い、内外の変化の影響を受け続ける
⇨　プロジェクトマネジメントでQCDのバランスを取り、価値を最大化する

### 成果物作成プロセス
- 求められた要件・方向に向かって進めず　→　手戻り
- 進捗・品質を定期的/定量的に把握せず  →  遅延
- 要求変更やリスクの発現に対応できず   →  作業肥大

  　　　　  ↑　適切なコストをかけて計画し、コントロールする

プロジェクトマネジメント

　　　　　　　　　　　→　実行  
立ち上げ　→　計画　　　　↓ ↑　　　          → 終結 <br>
　　　　　　　　　　　→  コントロール

**1~2割の時間を割いて、プロジェクトマネジメントにかける**

### 独自性と有期性に伴い発生する問題
- 定義された仕様に、のちのち変更が生じる
- 当初の見積もりを超えた作業が発生する
- 進捗・品質の実態がつかめず遅延・トラブルが生じる <br>
                    ⇩ <br>
⭐︎ 仕様を明確に/変更に適切に対応 <br>
⭐︎ できるだけ正確な見積もりをしたい <br>
⭐︎ 定量的に管理し精度を上げたい <br>
