# CPE 模擬クイズアプリ

標準編と上級編の問題・解説Markdownを自動で読み込み、ブラウザ上で出題する静的Webアプリです。

## 主な機能

- 標準編100問と上級編50問を切り替え
- 章別、10問・20問・50問・全問から出題数を選択
- 単一選択と複数選択に対応
- 回答後に正誤と解説を表示
- 正答率を集計
- 間違えた問題だけを再出題
- スマートフォン表示に対応

## ローカルでの開き方

リポジトリのルートでWebサーバーを起動し、次のURLをブラウザで開きます。

`http://localhost:8000/CPE/quiz-app/`

Markdownファイルをブラウザから読み込むため、`index.html`を直接開く方法では動作しません。
